# Leonardo Synthesis Skill (Modern Version)

**Solve problems the way Leonardo da Vinci did — by connecting ideas from the body, nature, buildings, and machines.**

Most people (and most AI) stay inside one field.  
This skill forces you to look at the same problem through several fields at once so you get better, more natural solutions.

## Quick examples

| Everyday problem              | Normal answer                  | Leonardo-style answer                                      |
|-------------------------------|--------------------------------|------------------------------------------------------------|
| Better water bottle           | Make it lighter and leak-proof | Shape it like a blood vessel + reservoir + classical proportions |
| City traffic jams             | Add more roads                 | Parallel routes + temporary “reservoir” zones like blood flow |
| Comfortable chair             | Add more cushion               | Use body proportions + tree-like flex + stable classical ratios |
| Team or app workflow          | Add more rules or features     | Parallel paths + buffer zones + pressure relief points     |

## What’s inside

- **SKILL.md** — Clear instructions written for modern people
- **scripts/analogy_mapper.py** — Finds useful comparisons across fields
- **scripts/proportion_checker.py** — Checks if sizes and ratios feel right
- **scripts/systems_analogy.py** — Models any system as pumps, channels, and storage

## How to try it yourself in 30 seconds

1. Write your problem in one sentence.
2. Ask: “How does the human body already solve something similar?”
3. Ask: “How does a river or a tree solve it?”
4. Ask: “How would a well-designed building solve it?”
5. Combine the best ideas.

That’s the whole method.

## Why it works

Leonardo’s notebooks show he constantly jumped between anatomy, water, architecture, and machines.  
This skill packages that habit so anyone (or any AI) can use it today.
