# Leonardo Synthesis Skill

Leonardo da Vinci inspired polymath synthesis skill for modern AI.

## Features
- Cross-domain analogical reasoning
- Proportional design checker & generator (Vitruvian / Archimedean / Golden)
- Systems analogy engine (flow, capacity, resistance across anatomy, hydraulics, architecture, mechanics)

Derived from the synthesis of books in Leonardo's notebooks (Euclid, Archimedes, Vitruvius, Aristotle, Alberti, Avicenna, Theophrastus, Frontinus, and others).

## Usage
See `SKILL.md` for full instructions.

## Scripts
```bash
python scripts/analogy_mapper.py "your problem description"
python scripts/proportion_checker.py
python scripts/proportion_checker.py generate 2.5 golden
python scripts/systems_analogy.py
```
